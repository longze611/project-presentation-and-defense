# 可执行的视觉系统

## 1. 配色

以下“源值”来自原PPT可直接读到的RGB记录，未把主题历史色误判为主色。面积比例与推荐字号属于本技能的设计建议。

| 角色 | 默认融合值 | 来源/依据 | 使用位置 |
|---|---|---|---|
| 白底 | `#FFFFFF` | A、B源值 | 主背景、证据底色 |
| 主学术蓝 | `#0B4FA1` | A源值 | 标题、主要线条、核心模块 |
| 模块蓝 | `#004EA2` | B源值 | 模块标题带、当前章节 |
| 辅助蓝 | `#0070C0` | B源值 | 次级标签、原生图表主系列 |
| 深蓝 | `#002060` | A、B源值 | 重要术语、深色文字 |
| 浅蓝 | `#A6BCE5` | B源值 | 表头层级、弱背景与细框 |
| 极浅蓝 | `#EAF2FF` | B源值 | 证据分区、表格汇总行 |
| 浅灰 | `#F3F3F7` | A源值 | 中性分区 |
| 正文黑 | `#1C1C1C` | B源值 | 正文与坐标标签 |
| 强调红 | `#C00000` | A、B源值 | 研究缺口、关键数值、风险 |
| 细线灰 | `#D7DDE7` | B源值 | 分隔线、表格弱边框 |

默认白色及浅底约占画面70%—85%，蓝色结构约10%—25%，红色约0%—5%。这些范围是视觉目标，主体照片或证据图可自然超出。红色每页建议1—3处，不整段染红，不同时混用多种红。B原稿的 `#FF0000` 可统一为 `#C00000`，源截图内部颜色不强制重染。

数据图的颜色由比较关系决定：基线用灰和浅蓝，主要方法用主蓝；红色只突出指定关键系列或异常。多分类超过4组时补充可分辨颜色并同步图例，不能把所有系列都涂成蓝。

## 2. 字体与字号

源A常见：思源黑体CN Bold/Regular/Medium/Heavy、思源宋体CN Heavy、Roboto；源B主要为微软雅黑，另有宋体、Times New Roman等。

推荐：标题与正文统一思源黑体或Noto Sans CJK SC；A式封面可用思源宋体Heavy。微软雅黑可用时也是B式合理选择。英文和数字使用Arial/Roboto/Calibri中已安装且匹配的字族；公式用可用的数学字体。确认字体实际存在，缺失时选择替代并记录，不能仅写字体名就假定渲染一致。

以下为13⅓×7.5英寸幻灯片的PowerPoint点数：

| 元素 | 推荐范围 |
|---|---|
| 封面主标题 | 36—48pt，短标题可达52pt |
| 封面副标题 | 24—30pt |
| 内容页标题 | 28—32pt |
| 模块标题 | 20—24pt |
| 正文 | 18—22pt |
| 图内标签、表格 | 16—18pt，复杂证据图可局部14pt |
| 图注、参考文献、页脚 | 10—12pt |

原参考出现36pt内容页标题和11—16pt正文等值；本表为改善投影可读性的推荐值。先保留参考的相对字号层级与信息密度，必要时优化小字，不自动改成每页只有少量大字的极简海报。

在1280×720 CSS像素画布中，1pt=4/3px。采用显式 `"20pt"` 等字体单位或进行换算。不要把20px当作20pt。图像阶段在2048宽度上20pt约对应42.7像素字高量级，仅用于沟通视觉尺度，最终以工具实际输出及阅读效果检查。

正文行距建议1.15—1.3，短列表行距可1.3—1.45。正文左对齐，表格数字对齐小数位。中文不逐字拉开，英文缩写不在字母间断行。字号不低于可读阈值来换取内容塞满。

## 3. 统一几何

布局逻辑画布1280×720，生成2048×1152时各位置乘1.6。坐标为设计起点，可针对长标题调整。

| 区域 | x / y / w / h，逻辑像素 |
|---|---|
| 页面安全区 | 48 / 32 / 1184 / 650 |
| 左侧蓝边标（可选） | 0 / 0 / 12 / 92 |
| 标题框 | 48 / 28 / 1184 / 58 |
| 标题下细线 | 48 / 100 / 1184 / 2 |
| 主体内容区 | 48 / 120 / 1184 / 532 |
| 来源与页脚区 | 48 / 668 / 1184 / 24 |

两栏默认间距24—32px，可按45:55、55:45或40:60分配；三栏等宽只用于确有三项对等内容。正文区底部需要结论带时预留48—64px，不能把图表挤到不可读。表格边框以0.5—1pt为主，研究流程连接线1.2—2pt。大圆角、厚阴影和按钮式装饰不是默认风格。

## 4. 页型库

### A-cover：正式蓝字封面

对应 [A01原页](../assets/references/a-cover.png)。白色大底，顶部小号本次学术汇报类型；中部深蓝高字重主标题，副标题小一级，题目控制在2行；下方居中放真实汇报信息。底部蓝色条带原页约占1/4，可随本次信息量调整，放真实单位或简洁信息；机构少时不模仿原稿堆砌十个单位。淡建筑/波纹可选。保留上部主题、下部身份的层级与大面积蓝白分区，不复刻原页的断行瑕疵。

### B-cover：横向蓝带封面

对应 [B01原页](../assets/references/b-cover.png)。浅灰白背景，中上部横贯页面的蓝色宽带，白字题目为视觉主体；横带右端可保留青蓝斜切几何层次。上方预留真实标识或机构信息区，无素材则留白；下方蓝字汇报信息。低对比度多边形纹理可选。两种封面二选一，结束页呼应同一方案，不继承竞赛标题或标识。

### Agenda：章节导航

- `A-agenda` 对应 [A02原页](../assets/references/a-agenda.png)：左约1/3深蓝竖栏，竖排“汇报提纲”和弱化的英文为可选元素；右侧白色内容区按等高横行列出编号、竖分隔线与章节名。当前章蓝底白字，其余浅底灰字，优化对比度保证可读。不用普通项目符号列表替代其分区结构。
- `B-agenda` 对应 [B02原页](../assets/references/b-agenda.png)：沿用内容页蓝标题、左边标与细横线，主体为等距的“独立编号方块＋长标题条”，当前项红底白字，其余浅底蓝字细蓝框。浅灰地图为可选，不添加无关地图信息。

章节数服从已审定正文，通常3—5组，不能硬凑成源稿数量。项目报告第2页必须有独立目录；章节切换时是否重复由导航价值决定。融合版默认采用A目录，与A封面及A结尾配套；选B家族时统一其红色当前项规则，不随机混用。

### Background：背景与研究缺口

顶部一行研究动机，左侧真实统计/领域现状，右侧现有方法不足；底部用一句有来源的研究缺口连接后续问题。避免“意义重大”等空泛句。浅蓝分区服务信息归类，不做无依据的装饰卡片网格。

### Related-work：文献比较

可编辑比较表占主体，列为方法、研究对象、核心机制、验证条件、局限；右侧或底部总结本文切入点。引用用短标号，全文信息放备注或文献页。行数过多时分组，默认4—6行主文献。

### Question：科学问题与研究目标

左侧研究对象和矛盾，右侧问题与拟验证关系；或上方研究目标、下方对应任务。每个目标可追踪到方法与验证，不以口号代替问题。

### Overview：总体框架与技术路线

中心图占约60%—75%主体面积，按输入、处理、输出组织。节点使用原生框及连接线，模块边界保持浅蓝；反馈关系与主流程用线型区分。整体结构复杂时，先总图后分图，分图可用红框标出当前区域。

### Method：方法展开

左侧约60%为方法图，右侧约40%为机制、与现有方法差别和预期可验证结果。核心方法标签为蓝底白字。开题稿的收益写为预期或待检验目标，不能套用参考B中的既成提升值。

### Formula：公式与机制

上部简短说明问题，左侧定义符号/输入，右侧主公式、变量含义和适用条件。避免公式、代码、截图同时塞满。公式与正文都是可编辑对象；生成图中的数学字形只用于视觉参照。

### Experiment-plan / Results：实验设计或真实结果

左侧40%—48%为数据集/实验条件表，右侧为比较图或实验流程；有真实结果时显示量纲、样本数、比较对象及误差含义。开题默认展示计划、基线和评价指标，不生成虚假结果曲线。两种状态不能混淆。

### Timeline：进度与交付

可编辑表格或甘特图呈现时间区间、研究任务、验证节点、阶段产物。时间由当前材料决定，不复制参考日期。若甘特图工具不能导出可编辑条目，用原生表格加形状重建并明确编辑方式。

### Risk

风险页只在内容需要时采用“具体风险—触发信号—应对方案”表。参考文献和备用证据根据用户页数要求安排，不自动扩页。

### A-closing / B-closing：与封面呼应的结尾

- `A-closing` 对应 [A19原页](../assets/references/a-closing.png)：保留A封面的白底、深蓝大字、下部真实汇报人、底部深蓝单位栏与可选淡纹理。主体改为1—2行正式结束语，字重和视觉强度呼应封面；不再套内容页页眉或填入密集结论。
- `B-closing` 对应 [B28原页](../assets/references/b-closing.png)：保留B封面的浅灰几何底、中上部蓝色宽带及右端斜切层次；横带内用大号白字结束语，横带下方保持宽松留白，必要时仅加少量真实身份信息。上方机构区域有真实素材才保留。

项目报告必须以独立结尾页收束，且逐页文案中须写出结束语。其他用途按需求选用。参照的是构图、配色、字体层级与首尾关系，结束语按本次受众改写，不复制源稿身份。

### 流程与分点页

优先读 [流程与分点呈现](process-and-points.md)，从蓝标签横条、分类侧签、并列研究模块、左问题右图、总图定位、方法图侧栏、纵向步骤、嵌套架构、证据链等真实参考结构中选取。它们比抽象的“蓝白配色”更能决定生成图片是否接近原稿。

## 5. 风格锁定

`style-lock.json` 至少固定：`variant`、`special_page_family`、`reference_anchor_ids`、`presentation_grammar`、`information_density`、`canvas`、`palette`、`fonts`、`font_sizes_pt`、`margins`、`header`、`footer`、`line_widths`、`red_usage`、`background_texture`。`special_page_family` 为 `A` 或 `B`，分别绑定A01/A02/A19或B01/B02/B28；特殊页面不硬套内容页标题框坐标与字号，按各自原页构图确定。`information_density` 默认 `technical-moderate-to-dense`；`background_texture` 默认 `none` 或 `very-subtle`，选择B原风格时可采用其低对比度背景。

除非用户更改，整套不能发生字体、标题左边距、标题带高度、红色语义或页码样式漂移。允许不同页型变换主体结构，不要求每页同样的三栏或同样的底部结论带。
